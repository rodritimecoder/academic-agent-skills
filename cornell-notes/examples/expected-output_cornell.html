Why do architectures use a memory hierarchy?

To balance trade-offs between access speed, storage capacity, and cost. High-speed SRAM caches sit close to CPU registers while slower, high-capacity DRAM acts as main storage.

comparison

What is the penalty of a cache miss vs cache hit?

Cache hits resolve in sub-nanosecond to a few nanoseconds (4-5 CPU cycles for L1). Cache misses require fetching from DRAM across the memory bus, taking 50–100 nanoseconds (~200+ cycles).

comparison

Compare the 3 cache placement policies

  • Direct Mapped: Each block maps to exactly 1 cache line; simple and fast hardware, but prone to frequent conflict misses.
  • Fully Associative: Blocks can reside in any line; eliminates conflict misses but requires complex, expensive parallel search hardware.
  • Set Associative: Balanced hybrid where cache is split into sets with N ways (e.g., 8-way set associative).

What are Temporal vs Spatial Locality?

  1. Temporal Locality: Memory accessed once is likely to be accessed again soon (e.g. loop index variables, repeated functions).
  2. Spatial Locality: Memory items physically adjacent to recently accessed items are likely to be accessed soon (e.g. contiguous arrays).
mechanism

How does loop ordering impact spatial locality in C?

Since C stores matrices in row-major order, traversing row-by-row maximizes cache line hits:

// Good spatial locality (row-major order in C)
for (int i = 0; i < N; i++) {
    for (int j = 0; j < N; j++) {
        sum += matrix[i][j];
    }
}

Traversing column-first (matrix[j][i]) causes stride misses on every iteration once the matrix exceeds cache capacity.
